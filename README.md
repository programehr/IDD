Source code for the paper Detecting Input-Dependent Backdoor Attacks via Poisoner Network Reverse Engineering.

To run attacks, you can use the [TrojanZoo](https://github.com/ain-soph/trojanzoo) (preferably version 1.0.8) or [Projan](https://github.com/programehr/Projan) codes.

To run the backdoor detection code, use [main.ipynb](./main.ipynb).
